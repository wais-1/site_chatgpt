# NOIR FRIESIAN — адаптивный сайт

Статический сайт на HTML, CSS и JavaScript. Включает главную, каталог, интерактивные карточки лошадей, адаптивное меню, анимации появления, форму обращения и Яндекс Карту через iframe.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в браузере или запустите локальный сервер из папки проекта:
   - Python: `python3 -m http.server 8000`
   - затем откройте `http://localhost:8000`

## Важно перед публикацией

- Данные о лошадях, адрес и телефон в макете являются демонстрационными. Укажите реальные проверенные сведения.
- `info@noir-friesian.example` использует зарезервированный домен `.example`, поэтому это не рабочий адрес электронной почты. В `script.js` и `index.html` замените его на настоящий адрес.
- Форма проверяет обязательные поля и подготавливает письмо в почтовом приложении пользователя (`mailto:`); она не отправляет заявки на сервер сама по себе. Для полноценной серверной отправки нужен backend или подключённый сервис обработки форм.
- Координаты карты соответствуют демонстрационной точке в Москве из макета, а не подтверждённому адресу конюшни.
- Шрифты загружаются с Google Fonts; если внешний доступ недоступен, используются системные запасные шрифты.
